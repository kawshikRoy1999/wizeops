🧠 AI Token Efficiency — Mind Map

Strategies to minimize token usage with Claude, Gemini, and other AI CLIs

⚡ Minimum Token Usage
with AI CLIs
✏️ Prompt Design
Be Specific, Not Verbose
State exactly what you need. Avoid filler phrases.
✗ "Could you please help me with..." ✓ "Fix null check in auth_bloc.dart:42"
Use Imperative Commands
Start with a verb. Skip pleasantries.
✓ "List", "Fix", "Add", "Rename", "Explain"
One Task Per Prompt
Combine only when tasks are tightly related. Separate unrelated asks.
Specify Output Format
Tell the AI exactly what to return to avoid long explanations.
✓ "Return only the dart code, no explanation" ✓ "Answer in under 3 bullet points"
🗂️ Context Control
Paste Only Relevant Code
Don't dump whole files. Paste the function or block that matters.
✓ "Here's the failing method: [paste 20 lines]" ✗ "Here's my whole project..."
Use File:Line References
In Claude Code CLI, reference files by path — it reads them itself.
✓ "Fix the bug in auth_bloc.dart line 42"
Clear Context Between Tasks
Start a new conversation for unrelated tasks. Old context burns tokens.
Use CLAUDE.md / System Prompts
Put persistent rules once in CLAUDE.md — not repeated in every message.
✓ Add: "No comments. No trailing summaries." to CLAUDE.md once.
📐 Response Shaping
Ask for Diffs, Not Full Files
Request only the changed lines, not the entire rewritten file.
✓ "Show only the changed lines" ✓ "Edit just the build method"
Suppress Explanations
Add "no explanation" or "code only" when you know what you want.
✓ "Fix it. Code only. No comments."
Cap Response Length
Constrain output to reduce unnecessary elaboration.
✓ "Answer in 1 sentence" ✓ "Under 5 bullet points" ✓ "Under 100 words"
🤖 Claude CLI Tricks
Use --print / Non-Interactive Mode
Pipe a single prompt for one-shot answers — no session overhead.
claude -p "explain this error: ..." --output-format text
Compact Sessions
Run /compact to summarize long conversations before continuing.
✓ Type /compact inside Claude session
CLAUDE.md for Standing Rules
Offload repeated instructions to CLAUDE.md — loaded once, not repeated.
Add: "No emojis. No summaries. Terse responses."
Use Haiku for Simple Tasks
Route trivial tasks (rename, format, grep) to claude-haiku-4-5 — cheaper & faster.
claude --model claude-haiku-4-5 -p "rename foo to bar in x.dart"
♊ Gemini CLI Tricks
Use Flash for Low-Stakes Tasks
gemini-2.0-flash uses far fewer tokens than Pro for simple tasks.
gemini --model gemini-2.0-flash -p "summarize this"
Pipe Input via stdin
Avoid re-explaining context — pipe the file directly.
cat main.dart | gemini -p "find bugs"
Set GEMINI.md / system instruction
Use system instructions once to avoid repeating tone/format rules per prompt.
Limit Output Tokens
Pass maxOutputTokens in API calls or use --max-output-tokens flag.
gemini -p "..." --max-output-tokens 200
♻️ Reuse & Caching
Prompt Caching (Claude API)
Mark stable context with cache_control. Cached tokens cost 90% less.
Add "cache_control": {"type": "ephemeral"} to large static system prompt blocks.
Reuse Session Within 5 Min
Claude's prompt cache TTL is 5 min. Send follow-ups quickly to hit cache.
Save Common Prompts as Scripts
Store refined prompts in shell scripts — reuse without retyping.
#!/bin/bash claude -p "Review $1 for security issues. Code only."
🔀 Smart Task Routing
Use CLI Tools Instead of AI
Don't ask AI to grep, find files, or run commands it can't execute.
✗ "Find all dart files with BlocBuilder" ✓ grep -r "BlocBuilder" lib/ --include="*.dart"
Tier Your Tasks by Complexity
Simple → Haiku/Flash. Medium → Sonnet. Complex → Opus/Pro.
Batch Small Tasks Together
Group 3–4 tiny related tasks in one prompt instead of 4 calls.
✓ "In auth_bloc.dart: 1) rename foo→bar 2) remove unused import 3) add const"
🔄 Habits & Workflow
Draft Prompts Before Sending
Write, trim, then send. Remove "I was wondering if..." type filler.
Prefer CLI over Chat UI for Code
Claude Code / Gemini CLI read files directly — no copy-pasting needed.
Never Re-explain Done Work
Reference what was done by file/line, not by retelling it.
✓ "Continue from auth_bloc.dart — now do the same for dashboard_bloc.dart"
Use /compact Before Big Tasks
Compact your session history before starting a new large feature.

⚡ Quick Cheat Sheet — Do / Don't

DO

Reference file:line instead of pasting full files

DON'T

Paste entire files or project structures unless asked

DO

Say "code only, no explanation" for known tasks

DON'T

Ask open-ended "what do you think about my whole app?"

DO

Use CLAUDE.md for rules that apply every session

DON'T

Repeat "always use Inter font, no comments" every prompt

DO

Use /compact when conversation gets long

DON'T

Keep one huge session for completely unrelated tasks

DO

Route simple tasks to Haiku / Flash models

DON'T

Use Opus/Pro for renaming a variable

DO

Send follow-up prompts within 5 min to hit cache

DON'T

Leave sessions idle 10+ min then re-ask the same context
